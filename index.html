На основе редактора Натальи Ситниковой

Предложение

Введите предложение, затем разметьте его вручную. Редактор не определяет члены предложения автоматически.

После изменения текста нажмите «Применить текст». Разметка неизменённых слов сохраняется; новые слова нужно разобрать.

Члены предложения и части речи

Нажмите на нужные слова, затем выберите член предложения. Повторное нажатие снимает выделение. Так можно подчеркнуть и составное сказуемое, и дополнение вместе с предлогом.

Характеристика предложения

Выберите вариант из подсказок или впишите свой. Пустые поля не попадут в скобки.

Оформление карточки

Предпросмотр внизу обновляется сразу.

Сохранение и экспорт

HTML — готовая карточка. JSON — проект, который можно снова открыть в этом редакторе.

Все линии включены в HTML. Интернет и установка программ для работы редактора не требуются. Сохраняйте проект JSON, чтобы не потерять изменения после закрытия страницы.
